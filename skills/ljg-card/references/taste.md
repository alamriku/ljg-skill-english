# Shared taste floor

The four molds may be completely different, but in all of them judgment comes before decoration.

## 1. Every visual must do work

Every generated image has to answer: which sentence does it let the reader *see* that words alone would not make visible?

- An action, an object, a tension; go easy on abstract light, floating geometry and generic AI imagery.
- Do not add an image because the layout looks empty. If deleting it changes nothing in understanding, it should never have been generated.
- Do not repeat the same metaphor, the same camera or the same asset inside one artifact.
- When an image in the source is evidence, cite it faithfully with its source; never regenerate one and pass it off as the original.
- In knowledge explanation, a concrete object must do discriminating work: the reader can point to the feature that puts it under the concept and the condition that changes the result. An analogy can aid understanding but never counts as an instance or evidence in the target domain.

## 2. Image and text have separate jobs

- Generated image: people, objects, scenes, actions, spatial relations, emotional tension.
- HTML/CSS: titles, body text, numbers, formulas, coordinates, labels, arrows, annotations, sources.
- No readable text, letters, numbers, logos, watermarks, fake labels or fake interfaces inside an image.
- Every image slot has a specific `alt` describing the action in the image and its relation to the body; never write "illustration".

## 3. Do not divide the layout evenly

- Never cut the content mechanically into thirds, quarters, or a row of identical cards.
- White space follows the narrative rhythm: a turn or a conclusion can be given room, while setup is kept tight.
- One main visual focus per page; everything else serves it.
- An image's composition must leave a safe area for the title, body or annotation in advance - never rescue it afterwards by dropping type on top.

## 4. Type and colour

- No Inter; prefer the mode's specified families and the system families for the content's script.
- Body text is never pure black `#000000`; use a warm black or a deep grey.
- The main colour has a role; never hand five or six saturated colours out evenly across modules.
- No gradients, heavy shadows, glassmorphism or glowing borders to manufacture "premium".
- Check type sizes against the 1080px artifact; never screenshot at desktop web type sizes.

## 5. Language and facts

- Judgments, mechanisms and conditions of application unfold naturally with the argument; they do not become fixed sections or a disclaimer at the end. Go easy on empty words like "empower", "reshape", "build out", "deep", "all-new".
- Never invent a number, a quotation, an organization, a name or a source.
- Never write the explanation into a generated image and rely on the model to spell it.
- Read every sentence back: it should sound like natural speech or mature prose, not translation-ese or template-ese.
- End on the content's own last sentence, followed only by the byline and the source. The scope of production, the acceptance status and generic reading reminders go into the delivery message, never appended to what the reader is reading; full-text mode keeps whatever the source itself contained.

## 6. No fake completion

- No remote random images, placeholders, fake logos or broken image links.
- No CSS icons or vector art posing as a finished concept visual.
- When the image tool is unavailable, the semantics are wrong, or the result contains fake text, retry in a targeted way at most twice; if a key image still fails, stop.
- Being able to open the HTML is not completion; you must produce the PNG and read it back pixel-wise.

## 7. Final visual check

- Hierarchy: within three seconds you can find the title, the main judgment and where to read next.
- Semantics: every image points back to one claim in the source; no generic decoration.
- Imagery: no fake text, no brand contamination, no cropped subject, no repeated assets.
- Text: no overflow, no occlusion, no undersized type, no orphan lines, no drifting source line.
- Long image: the whole image once, plus overlapping top/middle/bottom slices covering the full height.
